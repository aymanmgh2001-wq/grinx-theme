# grinxtheme

GRINX — Premium Shopify OS 2.0 theme

This repository was created by GitHub Copilot to host the GRINX Shopify theme (OS 2.0). The branch `grinx-theme` contains the full theme scaffold (sections, templates, assets) and is intended for installation in a Shopify store.

Notes:
- I was provided a logo image by the merchant during setup. Please upload the logo image to the theme's `assets/` folder as `logo.png` (or replace `assets/logo-fallback.svg`).
- If you have a custom font (`.woff2`), upload it to `assets/` and update `layout/theme.liquid` to preload it.

To install the theme locally:
1. Install the Shopify CLI: https://shopify.dev/themes/tools/cli
2. Clone this repo and checkout the `grinx-theme` branch.
3. Run `shopify theme push --dir=.` (or follow the Shopify CLI instructions) to upload to your Shopify store.
